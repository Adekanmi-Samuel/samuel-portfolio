Systems on record

Three deployments. Each one was built inside AI development environments, reviewed piece by piece, documented, and shipped.

01 / Content system

T World Post Creator

An AI assisted content platform for a social product. Users enter a topic, get generated post content, receive media recommendations from their own file library, and publish when ready.

Context
A technical assessment required a complete backend and frontend system for AI content creation, with documentation good enough for an engineering team to review.
What I did
Directed the full build end to end. Defined the architecture, specified the API surface, reviewed every generated file, wrote the operational documentation, and deployed the result for review.
System pieces
Post generation and regeneration, content improvement, hashtag suggestions, media recommendations with relevance scoring, asset picker, file moderation states, save and publish flow, structured logging.
Tools
Node.js, Express, MongoDB, React, TypeScript, Tanstack Router, Zustand, OpenAI compatible API, Vercel deployment.
Outcome
Working production deployment with architecture overview, model and cost analysis, production readiness notes, sample API responses, and 13 passing unit tests. Source shared as a public repository for technical review.
Content system Deployed
02 / Automation

Content and ops pipelines

Repeated content and operational tasks that should run without a human doing the same thing every week. Built for what happens after the first demo.

Context
Workflows for content generation, media processing, and research tasks that were slow, manual, and easy to forget.
What I did
Designed the automation flow, connected AI tools and APIs, set up triggers and routing, added fallback behaviour when a model or service fails, and documented how to operate the pipeline.
System pieces
Speech to text processing, text to media steps, API integrations, local model calls where cloud is not appropriate, logging for every run.
Tools
Composio, MCP servers, Playwright, Ollama, Whisper, ffmpeg, moviepy.
Outcome
Pipelines that handle content and operational tasks with minimal human intervention, and clear notes on what each stage does when something breaks.
Pipelines Operational
03 / Agent systems

Multi step agent workflows

Systems where an agent has a goal, uses tools, and completes work in several steps. A person sets the objective and reviews the result.

Context
Tasks that need tool use, memory, and several connected steps, where a single prompt and a single response are not enough.
What I did
Specified how agents should behave, which tools they can call, how failures should be handled, and where a human needs to approve before the system continues.
System pieces
Agent orchestration, tool calling, MCP compatible tooling, semantic memory concepts, automated workflows with supervision points.
Tools
MCP servers, Composio, Claude, Ollama, Python, JavaScript.
Outcome
Agent workflows that can research, call tools, and complete multi step tasks, with a clear boundary between autonomous work and human review.
